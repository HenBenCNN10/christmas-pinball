# Christmas Pinball — By Henry :)

A single-file, playable holiday pinball game. Open `index.html` in a modern browser to play.

## Controls

- **Left flipper:** Left Arrow or A (or hold the left on-screen button)
- **Right flipper:** Right Arrow or D (or hold the right on-screen button)
- **Launch:** Hold Space to charge the plunger, then release (or hold/release the Launch button)
- **R:** Start a new game
- Use **Sound on/off** to toggle synthesized arcade sounds.

Includes a start screen, animated snowfall and Christmas tree, bumpers, slingshots, lives, score, and a locally saved high score. On phones, use the touch controls.
